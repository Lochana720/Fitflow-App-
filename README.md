# FitFlow Redesign  Redesign of the FitFlow fitness tracking app, addressing personalization, social isolation and tracking-friction issues identified in the FitFlow user research study.  ## Tech Stack - Frontend: React Native (+ React Native Web) - Backend: Node.js + Express - Databases: PostgreSQL, Firebase Firestore - Auth: Firebase Auth - AI: TensorFlow Lite + cloud models, ML Kit (computer vision) - Cache: Redis  ## Documentation See /docs for the technology comparison tables, the weighted decision matrix, the high-level architecture diagram, and the Architecture Decision Record (ADR).  ## Getting Started 1. Clone the repo 2. Install dependencies in /frontend and each /backend service 3. Configure Firebase and PostgreSQL environment variables 4. Run services locally via docker-compose (see /docs)
